# Моделирование банковского счёта (ООП на Python)

В данном репозитории реализованы классы `Account` и `CreditAccount`.

## Основной функционал
- Пополнение счёта (`deposit`) и снятие средств (`withdraw`).
- Логирование истории всех операций с датой и временем (`datetime`).
- Поддержка кредитного лимита в классе-наследнике `CreditAccount`.
